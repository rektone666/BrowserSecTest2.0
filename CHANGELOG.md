# Changelog

## 0.1.0 — Initial test build

- Single Go executable with embedded browser interface and no runtime dependencies.
- Automatic loopback server lifecycle with random per-scan token.
- 25 browser-security, privacy, storage, permission, fingerprinting, and legacy-technology modules.
- No automatic camera, microphone, location, file, password, or account prompts.
- Plain-language HTML report plus structured scored and raw JSON reports.
- Default-browser launch, selectable browser commands, interactive console, and module listing.
- Cross-platform build script for Linux, Windows, and macOS on amd64 and arm64.
